# Navidrome для Murglar

Плагин для [Murglar](https://github.com/badmannersteam/murglar-plugins), который подключается к своему серверу
[Navidrome](https://www.navidrome.org/) или к любому другому Subsonic-совместимому серверу через Subsonic API.

## Возможности

- Избранное: треки, альбомы и исполнители. Лайк в Murglar = звёздочка в Navidrome.
- Плейлисты.
- Все исполнители, жанры, случайные треки.
- Альбомы: новые, недавно игранные, частые, случайные, все по алфавиту.
- Поиск по трекам, альбомам и исполнителям.
- Воспроизведение:
  - оригинальный файл, FLAC без перекодирования;
  - перекодирование на сервере в MP3 320 или 128 kbps.
- Скробблинг в Navidrome: «сейчас играет», затем засчитанное прослушивание (после половины трека или через 4 минуты).
  В режиме повтора одного трека прослушивания не засчитываются: Murglar не сообщает плагину о каждом новом круге.
- Тексты песен, в том числе синхронизированные (`getLyricsBySongId`, OpenSubsonic).
- Готовые теги из файла (например, проставленные Picard) и ReplayGain.

## Установка

1. Скачайте `murglar-plugin-navidrome-*.apk` из [Releases](../../releases) и установите его.
2. Полностью закройте Murglar и откройте его снова. Плагин появится в списке сервисов.

После обновления плагина Murglar тоже нужно закрыть полностью, иначе он продолжит работать со старой версией.

## Вход

Нужны адрес сервера, логин и пароль. Адрес можно писать коротко, например `192.168.1.5`; тогда подставятся `http://` и порт `4533`.
Пароль не сохраняется: хранится только токен `md5(пароль + соль)`, как требует Subsonic API.

## Автопоиск сервера

Это сделано для случая, когда ноутбук с Navidrome подключён к точке доступа на телефоне и при каждом переподключении получает новый IP.

- Если сохранённый адрес не отвечает, плагин перебирает локальную /24-сеть телефона (Wi-Fi или точку доступа) на том же порту.
  Найденный сервер он проверяет запросом `ping` с вашими учётными данными и сохраняет его новый адрес.
- Обычно поиск занимает пару секунд.
- Поиск можно запустить вручную в настройках плагина (**«Найти сервер»**) или там же выключить.

Ограничение: ссылки на обложки, уже закэшированные Murglar, ведут на старый IP. Свежие списки открываются уже с новыми ссылками.

## Сборка

Собирается в GitHub Actions (`.github/workflows/build.yml`). Готовые APK и JAR лежат в артефактах сборки, а для тегов `v*` — в Releases.

Секреты репозитория для подписи:

| Секрет | Значение |
|---|---|
| `KEYSTORE_BASE64` | keystore в base64 |
| `STORE_PASSWORD` | пароль keystore |
| `KEY_ALIAS` | алиас ключа |
| `KEY_PASSWORD` | пароль ключа |

Для локальной сборки скопируйте `local.template.properties` в `local.properties`, заполните его и запустите `./gradlew build`.
